## Flowchart Symbols — Quick Reference

| Symbol | Shape | Used for |
|---|---|---|
| Terminator | Oval / rounded rectangle | Start and Stop |
| Input / Output | Parallelogram | Reading values and printing results |
| Process | Rectangle | Calculations and assignments |
| Decision | Diamond | Conditions with Yes / No branches |
| Connector | Small circle | Joining parts of a large flowchart |
| Flow line | Arrow | Direction of the logic |

> **Plain-text flowchart notation used in the answers:**
> `[ ... ]` = process / input / output, `< ... ? >` = decision,
> `──Yes──►` / `──No──►` = branches, and `▼` / `▲` = flow direction.
